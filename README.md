# 🏗️ Расчет прочности бетонной балки на изгиб

**Лабораторная работа по веб-программированию**  
Django приложение для расчета прочности бетонных балок с интеграцией MinIO

## 📋 Описание проекта

Веб-приложение предназначено для:
- Выбора марок бетона из каталога
- Расчета прочности бетонных балок на изгиб
- Работы с изображениями через MinIO объектное хранилище
- Демонстрации архитектурного паттерна MVT

## 🛠️ Технологический стек

- **Backend:** Django 5.2.6, Python 3.13
- **Frontend:** HTML5, CSS3 (Flexbox), Django Templates
- **Database:** SQLite3 (встроенная)
- **Storage:** MinIO (объектное хранилище для изображений)
- **Architecture:** MVT (Model-View-Template)

## 🚀 Запуск проекта

### Предварительные требования
- Python 3.13+
- Docker (для MinIO)

### Установка и настройка

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/fenix15-05/concrete-beam-calculation.git
   cd concrete-beam-calculation
   ```

2. **Создание виртуального окружения:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   # source .venv/bin/activate  # Linux/Mac
   ```

3. **Установка зависимостей:**
   ```bash
   pip install django
   ```

4. **Запуск MinIO (Docker):**
   ```bash
   docker-compose up -d
   ```

5. **Запуск Django сервера:**
   ```bash
   python manage.py runserver 8000
   ```

6. **Открыть в браузере:**
   ```
   http://localhost:8000
   ```

## 🔄 Архитектура MVT

### Model (Модель)
- **Файл:** `flexural/data.py`
- **Содержит:** Данные марок бетона, расчеты, коэффициенты прочности

### View (Представление/Контроллер)
- **Файл:** `flexural/views.py`  
- **Функции:**
  - `grade_list()` - список марок с поиском
  - `grade_detail()` - детали марки бетона
  - `calculation_detail()` - страница расчетов

### Template (Шаблон)
- **Папка:** `flexural/templates/flexural/`
- **Содержит:** HTML шаблоны с Django Template Language

## 🔍 Функциональность

### 🏠 Главная страница (`/`)
- Каталог марок бетона (M100, M150, M200, M250, M300)
- Поиск по коду марки и названию
- Кнопка корзины с счетчиком услуг
- Изображения из MinIO хранилища

### 📋 Детали марки (`/grade/<id>/`)
- Подробная информация о марке бетона
- Характеристики прочности
- Изображение материала

### 🧮 Страница расчетов (`/calculation/<id>/`)
- Параметры балки (высота, длина, ширина)
- Результаты расчета максимальной нагрузки
- Сравнение марок бетона

## 🌐 HTTP/OSI модель

### Уровни OSI в проекте:
- **Прикладной (7):** HTTP/HTTPS протокол, Django приложение
- **Представления (6):** HTML, CSS, статические файлы  
- **Сеансовый (5):** HTTP сессии
- **Транспортный (4):** TCP соединения

### HTTP методы:
- **GET /** - получение списка марок
- **GET /?q=поиск** - фильтрация марок
- **GET /grade/1/** - детали марки
- **GET /calculation/1/** - страница расчетов
